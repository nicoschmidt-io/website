In mehr als 1.700 öffentlichen Schulen im brasilianischen Bundesstaat Paraná prüft eine Gesichtserkennung, wer im Unterricht sitzt. Die Lehrkraft fotografiert die Klasse, die Software gleicht die Gesichter ab. Sie stammt von Innovatrics, einer Firma aus Bratislava. In Europa haben Datenschützer und Gerichte ähnliche Versuche an Schulen gestoppt, in Schweden gab es dafür 2019 sogar ein Bußgeld.

Wen das System nicht erkennt, der gilt als abwesend. Weil die Anwesenheit an das Sozialprogramm Bolsa Família gekoppelt ist, könnten Fehler Familien Geld kosten. Eine Studie kam auf eine Trefferquote von 91,1 Prozent, vertraglich gefordert sind 95. Die Staatsanwaltschaft klagt, der Bundesstaat hält das System für rechtmäßig. Ein Exportverbot für solche Technik gibt es in der EU nicht.
